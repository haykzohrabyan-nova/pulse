Wipe Pulse data in this browser

Runs wipeAllPulseBrowserData() from shared.js. This removes:

  • All IndexedDB stores in BazaarPrintDB (orders, invoices, personnel, dies, purchase orders, …)
  • localStorage keys starting with pulse_, Supabase auth tokens (sb-*-auth-token), and admin-next state
  • sessionStorage pulse_session and op_operator — you’ll need to log in again

Cloud / Postgres: this page does nothing on the server. In Supabase, run supabase/migrations/016_clear_orders_and_audit.sql (SQL Editor) to delete all job tickets, invoices, and activity rows.

Choose an action below — or append ?automated=1 to this page URL when opened locally (file:// or localhost) to wipe immediately without prompts.
